Zo werkt het

  • WorkPortal stuurt de PDF via de Printix Cloud Print API naar de gekozen printer; die print direct (geen vrijgave bij de printer).
  • Handmatig printen: Beheer > DC01, vink ordermappen aan en kies Orderbon printen, of de knop Orderbon printen bij een order/project.
  • Printix-gegevens maak je in Printix Administrator bij de Cloud Print API (Printix Premium nodig; Secure Print mag niet op "Alle gebruikers moeten veilig printen" staan).
